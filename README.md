# 🔱 Global Currency Tracker                      [![Live Demo](https://img.shields.io/badge/Live_Demo-Global_Currency_Tracker-FF4B4B?style=for-the-badge&logo=streamlit&logoColor=white)](https://YOUR-APP-URL.streamlit.app)

An interactive real-time global currency converter and analytics dashboard built using **Streamlit**, **Plotly**, and **Pandas**, powered by the free **Open Exchange Rates REST API**.     

## 🚀 Features
- 🟢 **Live API Integration:** Fetches exchange rates for 160+ currencies with automated 5-minute caching.
- 💵 **Instant USD Converter:** Convert USD to any target currency dynamically via sidebar controls.
- 📊 **Interactive Plotly Visuals:** Compare key major currencies (EUR, GBP, EGP, CAD, AUD, CHF, CNY, AED) with value labels.
- 🛡 **Fail-Safe Fallback:** Offline fallback dataset guarantees uninterrupted app availability.
- ⚙️ **Cache Controls:** Dev options to manually purge Streamlit data cache.

## 🛠️ Tech Stack
- **Framework:** Streamlit
- **Data Manipulation:** Pandas
- **Visualization:** Plotly Express
- **HTTP Client:** Requests
